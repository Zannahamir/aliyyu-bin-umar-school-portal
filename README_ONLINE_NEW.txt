ALIYY BIN UMAR ONLINE SCHOOL PORTAL — NEW VERSION

This package is the online version for deployment to Render.
Features:
- Admin login
- Student registration
- Fixed Class 1, Class 2, Class 3
- All Students list
- Male (Maza) and Female (Mata) filters
- Daily Attendance / Presence: Present, Absent, Late
- Payment / Fees register
- Qur'an records
- Class totals with male/female counts
- Reports and full backup
- PostgreSQL database
